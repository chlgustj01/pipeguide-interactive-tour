가장 쉬운 첫 실습

  1. 시작 화면에서 EXPLORE SHIP을 누르세요.

    작업 흐름 화면이 열립니다. 작업 시작을 누르거나 도면분석 카드의 도면 업로드를 선택하세요.

  2. 도면 분석에서 샘플 프로젝트를 여세요.

    샘플 프로젝트 열기에는 공개 도면 5장과 미리 읽은 결과가 들어 있습니다. 직접 파일을 준비하지 않아도 됩니다.

  3. AI 정보 추출 → 결과 검토를 따라가세요.

    샘플은 인식이 끝나 있어 바로 결과를 검토할 수 있습니다. 항목을 누르면 원본 도면에서 해당 라인번호 위치를 찾을 수 있습니다.

  4. 검토 완료 · 3D 생성으로 → 3D 모델 생성을 누르세요.

    생성 리포트의 배관·장비 수와 만들지 못한 배관을 확인하세요. 생성 완료가 모든 배관의 성공을 뜻하지는 않습니다.

  5. 변경 영향 분석 시작을 누르세요.

    연습 예시: 목록에 733-443이 있으면 현재 구경을 확인하고 ¾″ → 1″로 바꿔 보세요. 연결 도면 같이 개정 → 3D 반영 · 영향 분석 순서로 진행합니다.

  6. 문제가 검출되면 경로 개선으로 넘기세요.

    간섭·이격 부족 항목 선택 → 선택 문제 경로 개선 → 대안 생성 → 후보 상세 검토 → 선택 후보 적용. 문제가 없다면 억지로 만들 필요 없이 3D 보기나 새 배관 연결을 연습하세요.

  7. 변경 보고서를 열고 결과를 저장하세요.

    전후 수치를 확인하고 보고서 HTML·PDF 또는 변경 이력 CSV를 저장하세요. 프로젝트의 ↶ 한 단계로 직전 변경을 취소할 수 있습니다.

TAB 01

프로젝트 — 전체 상황을 보는 출발점

배 전체와 기관실 위치, 도면 현황, 주요 경고, 변경 이력을 한눈에 보기 위해 설계했습니다.

이 탭에서 얻을 것 지금 어떤 도면과 모델을 보고 있는지, 무엇부터 처리해야 하는지 파악합니다.
  1. 전체 선박에서 기관실을 찾아보세요.

    기관실 구역 이름이나 구역 버튼을 눌러 위치를 확인합니다.

  2. 기관실 작업 공간을 여세요.

    기관실 작업 공간 열기를 누르면 기관실 3D를 자세히 볼 수 있습니다. 도면이 없다면 도면 올리기부터 시작하세요.

  3. 오른쪽 경고와 최근 변경을 읽으세요.

    경고를 선택해 관련 검토 화면으로 이동하고, 최근 변경 이력에서 수정 내용을 확인하세요.

TAB 02 · STEP 01

도면 분석 — 그림을 검토 가능한 정보로

도면을 올리고, 글자를 읽고, 사람이 바로잡은 뒤 3D를 만드는 과정을 4단계로 묶었습니다.

01 도면 업로드02 AI 정보 추출03 결과 검토04 3D 생성
  1. 01 도면 업로드

    PNG·JPG·WEBP 파일을 놓거나 선택합니다. 한 도면을 나눴다면 같은 이름 끝에 _1, _2, _3을 붙여 묶습니다. 처음에는 샘플 프로젝트 열기를 추천합니다.

  2. 02 AI 정보 추출

    정보 추출 시작을 눌러 아직 읽지 않은 도면을 순서대로 인식합니다. 라인번호·구경·장비 태그·다른 시트 표시를 읽습니다. 직접 올린 도면의 글자 인식에는 인터넷이 필요합니다.

  3. 03 결과 검토

    오른쪽 항목을 누르고 왼쪽 원본과 비교합니다. 선택한 라인번호는 빨간 점선으로 표시됩니다. 맞으면 ✓ 맞음, 구경이 틀리면 올바른 값을 골라 구경 수정을 누르세요.

  4. 04 3D 생성

    검토 완료 · 3D 생성으로 → 3D 모델 생성. 인식한 도면이 2장 이상이어야 합니다. 생성 리포트를 보고 변경 영향 분석 시작으로 이동합니다.

‘AI 정보 추출’이 읽는 범위

여기서는 주로 글자 인식(OCR)을 합니다. 도면의 모든 선 연결이나 실제 설치 좌표를 읽어 그대로 3D로 복제하는 기능은 아닙니다. 장비 위치·노즐은 규칙에 따른 가정 배치입니다.

화면의 버튼·조작언제, 어떻게 쓰나요?누른 뒤 확인할 것
도면 놓기·파일 선택 / + 도면 추가도면 그림을 추가합니다.지원 형식은 PNG·JPG·WEBP입니다. PDF는 이 기본 업로드에서 직접 받지 않습니다.
샘플 프로젝트 열기공개 도면 5장과 미리 인식한 결과로 연습을 시작합니다.샘플을 연 뒤 도면 목록과 인식 상태를 확인하세요.
도면 목록 / 조각 1·2·3검토할 도면과 그 도면의 이미지 조각을 고릅니다.현재 보고 있는 도면 이름을 확인하세요.

3D — 공간 안에서 배관을 이해하기

평면 도면만으로 보기 어려운 배관 겹침, 장비와의 거리, 연결 위치를 확인하기 위해 설계했습니다.

  1. 먼저 모델이 있는지 확인하세요.

    도면 분석의 3D 생성까지 마친 뒤 이 탭을 여세요. 빈 화면이면 도면 분석으로 돌아가 생성 상태를 확인합니다.

  2. 배관을 클릭해 정보를 읽으세요.

    트리 또는 3D 배관을 누르면 선택 정보가 열립니다. 장비·구조물을 누르면 사양 정보를 볼 수 있습니다.

  3. 복잡하면 격리하고 실치수로 확인하세요.

    격리로 주변을 흐리게, 전체로 화면을 다시 맞춥니다. 굵기 비교는 실치수를 사용하세요.

TAB 04 · STEP 02

변경 영향 — 하나를 바꿨을 때 어디까지 영향을 받나

배관 굵기 변경이 다른 도면, 양 끝 장비, 3D 공간에 미치는 영향을 연결해서 보여 주기 위해 설계했습니다.

  1. 변경할 배관과 새 구경을 고르세요.

    왼쪽 위 목록에서 배관·구경을 고른 뒤 구경 변경을 누릅니다. 현재 값과 바꿀 값을 다시 읽으세요.

  2. 영향 계통에서 연결 도면을 확인하세요.

    같은 라인번호가 있는 도면을 찾아 구경이 일치하는지 표시합니다. 필요한 경우 연결 도면 같이 개정을 누릅니다.

  3. 3D 반영 · 영향 분석을 누르세요.

    도면 데이터의 구경 변경을 3D 모델에 적용한 뒤 간섭·이격을 다시 검사합니다. 도면 값을 바꾸는 것과 3D에 반영하는 것은 별도 단계입니다.

  4. 문제 종류에 맞게 처리하세요.

    간섭·이격 부족은 경로 개선으로, 도면 불일치·미반영·누락은 데이터 확인·정정으로 이어집니다. 수정 후 재검증해 문제가 사라졌는지 확인합니다.

배관 선택 / 새 구경 선택변경할 대상과 새 크기를 정합니다.배관 번호와 현재 구경을 함께 확인하세요.

3D 반영 · 영향 분석 →구경 변경을 모델에 반영하고 공간 영향을 검사합니다.미반영 상태가 해소됐는지, 간섭·최소 이격을 확인하세요.

결과 문구를 이렇게 읽으세요.

문제 검출은 시스템이 발견했다는 뜻, 경로 개선은 우회 후보를 만드는 작업, 해결은 수정 후 재검증에서 사라진 상태입니다. 현재 검사는 응력·유량·모든 선체 구조와 선급 적합성을 전부 검증하지 않습니다.

경로 개선 — 후보를 보고, 검토한 뒤 적용하기

기존 배관의 문제 구간만 우회하거나 두 장비 사이에 새 배관을 만드는 작업 공간입니다.

A. 기존 배관 개선

  1. 문제 확인

    변경 영향에서 넘긴 배관 또는 오른쪽 목록·3D에서 배관을 선택합니다. 대안 생성을 눌러 우회 후보를 찾으세요.

  2. 후보 선택 · 비교

    후보 A/B/C 중 나온 후보를 누릅니다. 길이·엘보 수·최소 이격·간섭 수를 보고 겹쳐 보기와 좌우 2분할로 비교하세요.

  3. 검토 후 적용

    후보 상세 검토를 누릅니다. 자동 검사와 사람이 확인할 항목을 읽고 변경 사유를 적은 뒤 ✓ 선택 후보 적용을 누릅니다.

  4. 적용 결과 확인

    변경 보고서를 열고, 변경 영향의 재검증으로 문제가 사라졌는지 확인하세요.

B. 새 배관 연결 (LLM)

장비 두 개를 연결하는 별도 작업입니다. 화면 이름에 LLM이 들어가도 장비 선택 방식과 규칙 해석은 API 키 없이 사용할 수 있습니다.

  1. 장비 선택

    ＋ 새 배관 연결 (LLM) → 시작 장비·목적 장비를 고릅니다. 3D에서 순서대로 클릭하거나 목록을 사용하고 구경을 정합니다.

  2. 후보 · 형성 과정

    배관 연결 실행을 누릅니다. 경로가 생기는 애니메이션을 보고 후보를 선택하세요.

  3. 검토 후 적용

    노즐·간섭·이격·도면 반영 필요 사항을 읽고 등록 사유를 적습니다. ✓ 새 배관 등록을 눌러 모델에 추가합니다.

검색·필터·눈 아이콘·격리를 확인한 뒤 전체를 누르세요. 분해 보기를 끄고 시점도 다시 맞춰 보세요.
