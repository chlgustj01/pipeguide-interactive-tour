발표자용 핵심 설명
관경을 변경하면 연결된 도면과 3D 모델의 영향을 함께 확인합니다. 도면 개정만 필요하면 관련 도면을 맞추고 재검증합니다. 간섭이나 이격 부족이 발생하면 그 문제를 경로 개선으로 넘겨 우회 후보를 생성합니다. 자연어 요청과 배관 생성 과정 재생은 별도로 실행해 시연할 수 있습니다.

발표 순서: 사례 A는 짧게, 사례 B는 문제 발견 → 경로 생성 → 3D 시각화 → 비교 → 적용·재검증에 시간을 더 배분하세요. 본 튜토리얼의 자연어 시연은 외부 LLM을 호출하지 않는 규칙 해석 모드입니다.

핵심 시연 다음에 확인할 기능

40단계는 주요 흐름을 다루는 연습입니다. 다음 기능은 전체 사용 설명과 원본 프로그램에서 별도로 확인하세요.

도면 연결 후보 승인·거부 · 데이터 신뢰성

도면 분석에서 라인번호의 원본 위치와 구경을 검토한 뒤, 도면 간 연결 후보의 동일 라인·시트 근거를 확인하고 승인하거나 거부합니다. 현재 시연은 샘플의 준비된 연결 결과를 사용하며 승인·거부 동작을 자동 실행하지 않습니다.

변경 이력 · 되돌리기 · 파일 저장

적용 뒤 변경 이력에서 배관 번호·변경 유형·전후 수치·사유를 확인합니다. 프로젝트의 ‘↶ 한 단계’는 가장 최근 변경을 취소합니다. 보고서 HTML, PDF 인쇄 저장, 변경 이력 CSV 및 프로젝트 JSON 내보내기는 원본의 해당 버튼에서 실행하세요. 이 튜토리얼은 다운로드와 되돌리기를 자동 실행하지 않습니다.

검사 근거 읽기 · RULE / TEAM / 도면 / 가정 배치

도면에서 읽은 사양과 규칙으로 가정한 3D 위치를 구분하세요. RULE·TEAM 표시는 적용된 규칙과 팀 설정의 근거를 확인하는 단서입니다. 현재 샘플 이격 기준은 25 mm이며, 화면의 실제 설정과 검사 범위를 함께 확인합니다. P&ID에서 읽지 않은 설치 좌표는 가정 배치이므로 설계 승인 근거와 동일하게 취급하지 않습니다.
